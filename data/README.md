# Canonical Song Data

`data/songs/` is reserved for website-ready Song Soliloquy JSON exports conforming to `song-soliloquy/v1.1`.

One file = one song analysis.

Filename convention: `{artist}-{song-title}-song-soliloquy.json`.

Do not place raw research dumps or temporary parser output here. A file marked `complete` should satisfy the master spec and data-integrity contract.
