# NotebookLM Workflow

## Recommended source stack

Use the project material as distinct layers rather than uploading only a finished video script.

1. **Lyrics / evidence layer** — the exact lyric source available to the project.
2. **Canonical analysis layer** — the complete Song Soliloquy analysis; this is the primary intelligence source.
3. **NotebookLM source pack** — metadata, themes, narrator profile, summaries, glossary, references, key bars, hottest bar, comparisons.
4. **NotebookLM questions** — the agenda that directs discussion toward meaningful analytical tensions.
5. **Optional voice/script guide** — hook, thesis, emphasis, and desired presentation character.

## Why this architecture

The analysis supplies arguments and interpretation; the lyrics supply evidence; the source pack compresses the most important context; the questions create discussion paths. A finished YouTube script is useful as a secondary framing source, but using it as the only source risks turning synthesis into paraphrase.

## Discussion goals

Prompts should encourage the hosts to examine worldview, technical craft, narrative perspective, production/lyric interaction, layered language, cultural references, the hottest-bar decision, and cross-song comparisons.

## Output reuse

NotebookLM discussion can feed back into editorial work as idea generation, but new claims should be verified before being promoted into the canonical JSON.
