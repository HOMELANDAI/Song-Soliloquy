# Research Toolkit

Song Soliloquy is designed to combine lyric interpretation with external music research.

## Research dimensions

| Dimension | Candidate source/tool | Purpose |
|---|---|---|
| BPM / tempo | Tunebat, SongBPM | Establish tempo and comparable tempo pockets |
| Key / harmony | Tunebat, Hooktheory | Key, mode, chord/progression relationships |
| Samples | WhoSampled and primary credits | Identify source recordings and sample lineage |
| Mood / audio descriptors | Cyanite | Add machine-assisted sonic/mood descriptors |
| Credits / release data | official releases, label/artist sources | Producer, features, album/project, release date |
| Lyrics / annotations | user-supplied source + research references | Evidence for analysis and cultural context |

## Cross-checking

Do not assume two music-analysis services will return identical BPM/key values. When values conflict, preserve the disagreement or establish a documented editorial choice.

## Provenance

Externally researched facts should eventually carry source, URL/reference, retrieval date, confidence, and verification state. Interpretive lyric analysis should not masquerade as externally verified fact.

## Comparison research

For each song, search for connections in at least these buckets when evidence exists:

- similar BPM;
- similar chord progression/key relationship;
- shared sample/sample source;
- similar production texture;
- shared cultural reference;
- analogous pun/entendre mechanism;
- similar rhyme architecture;
- thematic or philosophical parallel.

The purpose is not to inflate a related-song list. It is to build explainable connections that can become a recurring editorial segment and, later, a knowledge graph.
